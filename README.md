# The Quant Surveyor (site)

The Quant Surveyor: a dashboard of global residential real estate built from open sold-price registers and official statistics. This repository holds
only the published pages, `meta.json`, the country layer and the index-only cities; sold-record city
payloads are served from regional data repositories (`rei-data-london`, `rei-data-uk`, `rei-data-europe`,
`rei-data-americas`, `rei-data-apac`). The engine that produces them is private.

What is here: repeat-sales indices to postcode-district level with uncertainty bands and an explicit
provisional tail, sold-record histories, price tiers and segments, seller outcomes, an H3 hex map, and a
country layer with a templated global read. See the Methodology page on the site.
